# Skin Lesion Classification

Master's Thesis Project (MSc in Big Data & Data Science)

## Authors

* Juan Guillermo Cardona Urrego
* Pau Peracaula López-Amor
* Carles Raich Bros

## Overview

This project investigates the use of machine learning methods for the classification of skin lesions from clinical images and associated metadata.

The objective is to evaluate whether predictive models can help distinguish potentially malignant lesions from benign lesions using data from the International Skin Imaging Collaboration (ISIC) 2024.

This work is conducted exclusively for academic and research purposes as part of a Master's Thesis.

## Dataset

The dataset used in this project is obtained from the ISIC 2024 Challenge:

https://challenge.isic-archive.com/data/#2024

The repository does **not** contain any images or patient data; images, metadata and derived datasets are excluded from version control.

Users must independently obtain the dataset from the official ISIC sources and comply with all applicable licensing terms.
