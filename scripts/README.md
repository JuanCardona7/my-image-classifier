# Scripts

This folder contains executable scripts used to generate project artefacts.

---

# Data preparation scripts

These scripts generate the metadata and image datasets used later for modelling.

Before running them, the raw ISIC 2024 SLICE-3D data must be downloaded from:

```text
https://challenge.isic-archive.com/data/#2024
```

The required dataset is **SLICE-3D**.

The raw files should be placed as follows:

```text
data/raw/metadata/
    ISIC_2024_Training_GroundTruth.csv
    ISIC_2024_Training_Supplement.csv
    metadata.csv

data/raw/images/
    ISIC_XXXXXXX.jpg
    ISIC_XXXXXXX.jpg
    ...
```

Images should be kept in the same format and naming convention as downloaded.

All scripts should be run from the project root using `uv`.

---

## 1. `preprocess_data.py`

Generates the first preprocessed metadata dataset from the raw CSV files.

This script loads the raw metadata tables, merges the relevant sources, standardizes the main identifiers and variables, performs the first cleaning steps, and saves an interim Parquet dataset.

Run:

```bash
uv run python scripts/preprocess_data.py
```

Expected output:

```text
data/interim/metadata/preprocessed_from_raw_<timestamp>.parquet
```

---

## 2. `final_preprocess_data.py`

Generates the final metadata dataset used for modelling.

This script loads the latest interim metadata dataset generated by `preprocess_data.py`, applies the final preprocessing decisions, prepares the modelling targets, and saves the final processed metadata.

If the required interim metadata file is not available, this script automatically runs `preprocess_data.py` first.

Run:

```bash
uv run python scripts/final_preprocess_data.py
```

Expected output:

```text
data/processed/metadata/final_preprocessed_from_raw_<timestamp>.parquet
```

---

## 3. `preprocess_images.py`

Generates the preprocessed image dataset from the raw JPG files.

This script loads the final processed metadata, matches each `lesion_id` with its corresponding JPG image, resizes all images to a fixed square size, stores the resized images as JPEG bytes inside Parquet files, and saves a JSON manifest.

If the final metadata file is not available, this script automatically runs `final_preprocess_data.py` first.

Run a small test first:

```bash
uv run python scripts/preprocess_images.py --limit 1000
```

Run the full image preprocessing pipeline:

```bash
uv run python scripts/preprocess_images.py
```

Useful arguments:

```bash
--image-size 136
--shard-rows 500000
--jpeg-quality 95
--single-file
--limit 1000
```

Default behaviour:

```text
image size: 136 x 136
JPEG quality: 95
rows per shard: 500000
```

Expected output for a single file:

```text
data/interim/images/raw_images_preprocessed_136_<timestamp>.parquet
data/interim/images/raw_images_preprocessed_136_<timestamp>_manifest.json
```

Expected output for multiple shards:

```text
data/interim/images/raw_images_preprocessed_136_<timestamp>_shard_000.parquet
data/interim/images/raw_images_preprocessed_136_<timestamp>_shard_001.parquet
...
data/interim/images/raw_images_preprocessed_136_<timestamp>_manifest.json
```

---

## Recommended workflow

Run the full metadata preprocessing pipeline:

```bash
uv run python scripts/final_preprocess_data.py
```

Then test the image preprocessing on a small subset:

```bash
uv run python scripts/preprocess_images.py --limit 1000
```

If the test works correctly, run the full image preprocessing:

```bash
uv run python scripts/preprocess_images.py
```

The scripts are designed to run sequentially, but later scripts can automatically generate missing previous datasets when needed.
